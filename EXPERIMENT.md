# Эксперимент: запуск установки без GUI

Эта ветка нужна для проверки полной двухсерверной цепочки без сборки Fyne.
Она **не меняет** основную ветку `main`.

Команда из корня репозитория:

```powershell
go run -mod=mod ./cmd/awg-chain-test
```

Понадобится Go 1.26+ и доступ к SSH обоих VPS с компьютера. При первом
запуске Go может один раз скачать только нужные Go-модули и создать локальный `go.sum`, но **не компилирует Fyne GUI**.

IP-адреса и SSH-порты задаются константами в
`cmd/awg-chain-test/main.go`; значения по умолчанию соответствуют
тестовой паре. SSH-пароли вводятся интерактивно **без отображения символов**
и не сохраняются в коде, конфигурации, репозитории или журнале.

После подтверждения словом `install` выполняется **полная установка**:
проверка чистых VPS, сборка AWG на обоих VPS, запись VPN-конфигураций,
настройка маршрутизации и проверка соединения. **Запускать только на
серверах без рабочих интерфейсов и правил VPN.**

Исходники берутся напрямую из официальных GitHub-репозиториев Amnezia и
закреплены за двумя commit SHA версии 3.1.20260812. Это HTTPS-доставка
исходников с фиксированными коммитами, **а не подписанные GPG .deb**.
Зависимости для сборки берутся из подписанных репозиториев Ubuntu.

При возникновении ошибки пришли текст последнего этапа: серверы
необходимо проверить перед повтором. VPN-ключи не публикуй.

Успешный профиль для Keenetic появится в папке `profiles` рядом
с исходниками. Его содержимое секретно.
