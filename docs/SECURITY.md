# Безопасность и ограничения

AWG Chain Installer выполняет команды от имени root на двух VPS. Устанавливайте его только на принадлежащих вам серверах и из доверенного релиза.

## SSH

При первом подключении установщик показывает SHA256-отпечаток ключа SSH. Сверьте его с консолью или панелью VPS-провайдера. После подтверждения ключ сохраняется в локальном known_hosts; изменение ключа блокирует подключение. Пароли не сохраняются в файлах и не печатаются в журналы.

Первая версия поддерживает только пользователя root с SSH-паролем. Не меняет SSH-пароли, sshd_config и доступ по SSH.

## Изменения на VPS

- Устанавливаются пакеты Ubuntu и AmneziaWG из официального PPA с проверкой GPG-отпечатка.
- Включается IPv4 forwarding и сервисы awg-quick@awg-destination, awg-quick@awg-mediator, awg-quick@awg-client.
- На входном VPS используются таблица маршрутизации 100 и правило PBR 1000; добавляются firewall-правила kill switch.
- На выходном VPS добавляются NAT, обратный маршрут и ограничение доступности UDP 51820 только для IPv6 входного VPS.
- Генерируется клиентский .conf с приватным ключом в указанной папке (0600 на Unix).

## Экспериментальная диагностика Managed by Amnezia

Вкладка **Amnezia VPN** использует только read-only команды (`ip link`, проверка наличия файлов и `docker inspect`) для обнаружения компонентов. Пароли не сохраняются. Она не устанавливает серверные контейнеры, не создаёт клиентов и **не позволяет** управлять контейнером из официального приложения сама по себе.

На действующих серверах программа поддерживает диагностику и старых (`awg-home`, `awg-fin`, `awg-spb`), и новых (`awg-client`, `awg-mediator`, `awg-destination`) имён. Переименование действующих интерфейсов не производится.

## Ограничения v0.1

- Только чистые VPS с Ubuntu 24.04 LTS x86_64, штатное ядро 6.8, доступные публичные IPv4 и IPv6.
- Фиксированные подсети 10.86.66.0/24 и 10.77.77.0/30; фиксированные UDP-порты 51821 и 51820. Убедитесь, что подсети не пересекаются с роутером.
- Не меняет существующий UFW, cloud firewall, чужие VPN-профили или конфликтующие маршруты: при конфликте установка останавливается.
- Если внешний firewall провайдера закрывает UDP, программа не может открыть его через SSH.
- В случае ошибки посреди установки изменения могут сохраниться частично. Автоматического полного отката в v0.1 нет. Сначала проверьте состояние серверов, прежде чем повторять установку.
- Успешная проверка подтверждает связь двух VPS и выходной IPv4. Проверка Keenetic возможна только после импорта файла на роутер.
- Роутерная конфигурация направляет IPv4. Если на Keenetic IPv6 включён напрямую, он может обходить VPN; настройте отдельную политику маршрутизации или ограничения.
- Вход по SSH под root с паролем менее устойчив к подбору, чем доступ по ключу, но программа не меняет предпочтения владельца.

Перед запуском рекомендуется сделать снапшот обоих VPS и убедиться, что консоль управления у провайдера доступна.
